# Робота з віртуальним середовищем (.venv) та тестами

Цей проєкт використовує **ізольоване віртуальне середовище (`.venv`)** для керування залежностями та бібліотеками, такими як `pytest`. Це гарантує, що інструменти цього проєкту не будуть конфліктувати з іншими програмами на вашому комп'ютері.

---

## 1. Як увійти у віртуальне середовище (Активація)

Перед початком роботи обов'язково потрібно активувати середовище. У терміналі VS Code (PowerShell) виконайте команду з кореня проєкту:

```bash
.venv\Scripts\Activate.ps1
```
*Ознака успіху:* На початку рядка вашого терміналу з'явиться зелений напис **`(.venv)`**.

---

## 2. Як запустити тести (Тестування)

Для автоматичної перевірки правильності роботи коду використовується бібліотека `pytest`.

* **Запустити абсолютно всі тести в проєкті:**
  ```bash
  python -m pytest
  ```
* **Запустити конкретний файл із детальним виводом (прапорець `-v`):**
  ```bash
  python -m pytest tests/test_calculation.py -v
  ```
* **Запустити тест і показати результати команд `print()` (прапорець `-s`):**
  ```bash
  python -m pytest tests/test_my_path.py -s
  ```

---

## 3. Як перевірити функції на будь-яких числах (Калькулятор REPL)

Якщо ви хочете протестувати свої функції з новими числами в реальному часі, не змінюючи файли коду, використовуйте інтерактивний режим:

1. **Запустіть Python:**
   ```bash
   python
   ```
   *(З'являться три стрілочки `>>>`)*

2. **Імпортуйте свої функції:**
   ```python
   from hw_08_prystatska.study_tools.calculations import mean, clamp, weighted_sum
   ```

3. **Рахуйте будь-які числа:**
   ```python
   >>> mean(10, 20, 30, 40)
   25.0
   >>> clamp(150, lower=0, upper=100)
   100
   ```

4. **Вийдіть з інтерактивного режиму:**
   ```python
   >>> exit()
   ```

---

## 4. Як вийти з віртуального середовища (Деактивація)

Коли ви завершили роботу над проєктом і хочете повернутися до звичайного системного терміналу, просто напишіть:

```bash
deactivate
```
*Ознака успіху:* Зелений напис `(.venv)` зникне з початку рядка терміналу.

## Інструкція із запуску (для Windows / PowerShell)

Для запуску проєкту та ізоляції середовища виконайте такі команди в терміналі з кореня папки проєкту (`hw_08_prystatska`):

1. **Створити локальне віртуальне середовище `.venv`:**
   python -m venv .venv
  
2. **Активувати віртуальне середовище:**
   .\.venv\Scripts\Activate.ps1

3. **Запустити демонстраційний скрипт `demo.py`:**
   python demo.py

4. **Вийти з віртуального середовища після завершення роботи:**
   deactivate
5. **Як правильно дізнатися поточну папку? Present Working Directory — теперішня робоча папка**
   pwd

### Перебір вмісту папки (iterdir)
метод .iterdir() дозволяє «зазирнути» всередину папки:
• Path("data").iterdir()           перебирає всі елементи, які знаходяться всередині папки data.
• item.is_file()                   перевіряє, чи є елемент звичайним файлом (тоді виводиться файл ім'я_файлу).
• item.is_dir()                    перевіряє, чи є елемент підпапкою (тоді виводиться папка ім'я_папки).

### Різниця між glob та rglob
методи для пошуку файлів за шаблоном (маскою):
• glob("*.txt") — шукає текстові файли тільки в поточній папці (на одному рівні, не заглядаючи всередину підпапок).
• rglob("*.txt") — працює рекурсивно (літера «r» означає recursive). Він знайде текстові файли і в поточній папці, і в усіх її підпапках, незалежно від глибини вкладеності.
⚠️ Не видаляйте і не перейменовуйте файли за знайденими шляхами, не перевіривши їх за допомогою .resolve(), щоб випадково не вийти за межі вашої цільової папки.
