# Імпорт та валідація оцінок студентів з CSV

Цей проєкт призначений для **автоматичного імпорту, валідації та фільтрації оцінок студентів** із файлів формату CSV. Скрипт покроково перевіряє коректність структури даних, типів та числових меж, розділяючи записи на успішно оброблені та відхилені з детальним описом помилок.

## Функціонал програми

*   **Конвертація та перевірка типів:** перетворення текстового значення оцінки на ціле число (`int`).
*   **Обробка тексту:** піднімає звичайний `ValueError` для нечислового тексту.
*   **Валідація діапазону:** піднімає `ValueError` з повідомленням, що оцінка поза діапазоном **0–100**.
*   **Стійкість до помилок структури:** обробка відсутніх стовпців (`KeyError`) та відсутності самого файлу (`FileNotFoundError`).
*   **Логування помилок:** збереження номера рядка, оригінальних даних та причини відмови для кожного некоректного запису.
*   **Гарантія якості:** використання блоку `assert` для фінальної перевірки успішних даних перед поверненням результату.

## Інструкція із запуску

### 1. Генерація тестових даних
Щоб створити тестовий файл `scores.csv` у потрібній директорії, виконайте команду в терміналі:
```bash
python hw_10_prystatska/create_test_data.py
```

### 2. Запуск головної програми імпорту
Для обробки створеного файлу та виведення результатів валідації в консоль виконайте:
```bash
python hw_10_prystatska/score_import.py
```

## Правила обробки даних (Приклади результатів)

Програма очікує CSV-файл зі стовпцями `student_id`, `name`, `score`. Нижче наведено приклади того, як скрипт реагує на різні типи вхідних даних:

### Успішно валідовані (Correct Data)
Записи, що містять ціле число від 0 до 100, потрапляють до списку успішних:
*   `1,Олена,95` → **95 балів**
*   `6,Катерина,0` → **0 балів**
*   `4,Марко,100` → **100 балів**

### Відхилені через помилки (Rejected Data)
Записи, що не пройшли перевірку, маркуються відповідною помилкою:

| Рядок | Вхідне значення | Тип помилки / Опис результату |
| :--- | :--- | :--- |
| **8** | `-5` | Обов'язкове числове значення: оцінка поза 0–100: отримано -5 |
| **11** | `105` | Обов'язкове числове значення: оцінка поза 0–100: отримано 105 |
| **14** | `""` (Порожнє) | Обов'язкове числове значення: invalid literal for int() with base 10 |
| **17** | `not` (Текст) | Обов'язкове числове значення: invalid literal for int() with base 10 |
| **18** | *Відсутнє поле* | Відсутнє обов'язкове заповнення оцінки: 'Відсутні дані 'score'...' |


*   **ValueError:** піднімає звичайний `ValueError`
 для нечислового тексту (наприклад, якщо замість оцінки вказано текст або порожній рядок `""`).
