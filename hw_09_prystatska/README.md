# Аналіз відвідуваності та генерація звітів студентів з CSV

Цей проєкт призначений для **автоматичного імпорту, валідації та аналізу відвідуваності студентів** із файлів формату CSV. Програма перевіряє коректність структурних даних, обчислює індивідуальний відсоток відвідуваності, визначає статус студента та розділяє результати на успішний звіт (`attendance_summary.csv`) і журнал зафіксованих аномалій (`issues.txt`).

## Функціонал програми

*   **Сувора валідація даних:**
    *   **Перевірка заголовків:** контроль наявності обов'язкових стовпців (`name`, `group`, `attended`, `total`).
    *   **Валідація імені:** дозволено лише літери, пробіли, апострофи та дефіси. Рядки з цифрами або спецсимволами відхиляються.
    *   **Валідація групи:** жорсткий шаблон структури (2 літери, дефіс, 2 цифри, наприклад: `КН-11`).
    *   **Аналіз числових показників:** контроль перетворення типів, захист від ділення на нуль (`total == 0`) та логічна перевірка лімітів (`attended > total`).
*   **Розрахунок відсотків та класифікація:**
    *   Обчислення відсотка відвідуваності: `(attended / total) * 100` з округленням до 1 знака після коми.
    *   Автоматичне присвоєння статусу: **`достатньо`** (якщо \(\ge\) 75.0%) або **`потрібно надолужити`** (якщо < 75.0%).
*   **Експорт результатів:**
    *   Запис усіх успішних записів у новий файл `attendance_summary.csv`.
    *   Експорт деталізованого списку помилок із зазначенням причини відхилення у текстовий файл `issues.txt`.
*   **Гарантія цілісності даних:** автоматичне повторне перевірочне читання створеного CSV-файлу та звірка кількості записів через блок `assert`.

##  Детальний розбір внутрішньої логіки програми

### 1. Перевірка формату коду групи (Алгоритми без Regex)
Валідація назви групи виконується шляхом покрокового аналізу структури рядка (очікуваний шаблон: `ХХ-99`, де `Х` — літера, `9` — цифра). Скрипт перевіряє такі критерії:
1. **Загальна довжина рядка** має дорівнювати рівно 5 символам (`len(group) != 5`).
2. **Роздільник (третій символ)** має бути дефісом (`group[2] != "-"`).
3. **Перша частина (індекс `0:2`)** повинна складатися виключно з літер (`.isalpha()`).
4. **Друга частина (індекс `3:5`)** повинна складатися виключно з цифр (`.isdigit()`).

*Альтернатива з використанням регулярних виразів (RegEx):*
Для спрощення коду цей алгоритм можна замінити еквівалентним патерном:
```python
import re
 2 кириличні/латинські літери, дефіс, 2 цифри
if not re.match(r"^[A-Za-zА-Яа-яЁёЇїІіЄєҐґ]{2}-\d{2}\$", group):
    print("Некоректна група")
```

###  Успішно валідовані (Записуються в `attendance_summary.csv`)
*   `Олена,КН-11,12,"10,14,8,10,5"` → Обчислений відсоток: **25.5%** | Статус: **потрібно надолужити**
*   `Влад,КН-12,1,"17,19,3"` → Обчислений відсоток: **2.6%** | Статус: **потрібно надолужити**

###  Відхилені записи (Фіксуються в `issues.txt`)
Програма логує кожну аномалію окремим повідомленням:

| Вхідна аномалія (Приклад) | Зафіксована помилка в `issues.txt` |
| :--- | :--- |
| `Петро, КН-10, not, " "` | *Не є числом або порожні дані 'attended' для 'Петро': 'not'* |
| `Мар'ян, К, 0, "100,11,сімдесять"` | *Некоректний формат 'total' для 'Мар'ян': '100,11,сімдесять'* |
| Порожнє ім'я (` ,КН-12, 7, 2`) | *Помилка: Ім'я студента порожнє* |
| Некоректний код групи (`Тетяна, , , 19,11,17`) | *Некоректна група для 'Тетяна': ''* |
| Присутні цифри в імені (`Марко, молодший 2`) | *Некоректне ім'я (містить цифри або заборонені знаки): '...'* |

#### Використання функції `mean` з модуля `hw_08`
Для визначення середнього значення балів програма використовує розроблену раніше функцію `mean`, яка імпортується за допомогою динамічного налаштування шляхів через системний модуль `sys`.

*   **Гнучкість функції:** Функція приймає аргументи через оператор розпакування `*student_scores`. Це дозволяє передавати в неї будь-яку кількість чисел через кому (наприклад, як один бал `mean(10)`, так і серію оцінок `mean(10, 14, 8, 10, 5)`).
