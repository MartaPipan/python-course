# Student Label

## 1. Опис завдання

Програма `student_label.py` приймає від користувача:

прізвище та ім'я студента;
код групи.

Програма очищає введені дані, перевіряє їх коректність і для правильного запису виводить:

прізвище та ім'я;
код групи у верхньому регістрі;
ініціали.

## 2. Вимоги до даних

### Повне ім'я

Ім'я повинно:
складатися рівно з двох слів;
містити тільки літери;
не мати зайвих пробілів на початку та в кінці;
мати один пробіл між словами;
кожна частина імені повинна починатися з великої літери.

Алгоритм програми:

```text
Алгоритм програми:

Введення даних
      ↓
strip() — очищення країв
      ↓
split() — поділ імені на слова
      ↓
join() — один пробіл між словами
      ↓
len() — перевірка кількості слів
      ↓
isalpha() — перевірка літер
      ↓
title() — перша літера велика
      ↓
upper() — група у верхньому регістрі
      ↓
len() — перевірка довжини групи
      ↓
[2] — перевірка дефіса
      ↓
[:2] + isalpha() — перевірка двох літер
      ↓
[3:] + isdigit() — перевірка двох цифр
      ↓
Виведення результату
```

## 9 Чому права межа зрізу не включається?

У Python зріз має форму
text[start:end]
Ліва межа включається, а права — ні.
Наприклад:
group = "КB-11"
print(group[:2])
Результат:

КB

Індекси:

К B - 1 1
0 1 2 3 4
-5 -4 -3 -2 -1

group[:2] бере індекси 0 і 1, але не бере індекс 2.
Тому права межа означає:
зупинитися перед цим індексом.
Це дозволяє зручно отримувати частини рядка.

Позитивні індекси рахуються зліва направо:

0 → 1 → 2 → 3 → 4

Від'ємні індекси рахуються справа наліво:

-5 ← -4 ← -3 ← -2 ← -1

## 10. Чому не потрібно створювати власний алфавіт?

Python підтримує Unicode, тому isalpha() може розпізнавати літери різних мов.
Наприклад:
print("Marta".isalpha())

# True

print("Марта".isalpha())

# True

print("Програмування".isalpha())

# True

Тому не потрібно створювати власний список або рядок усіх можливих літер:

alphabet = "abcdefghijklmnopqrstuvwxyz..."
і перевіряти кожну букву вручну.

Метод isalpha() вже виконує цю перевірку з урахуванням Unicode.
Це робить програму коротшою та дозволяє працювати не тільки з латиницею, а й з українськими та іншими Unicode-літерами.
