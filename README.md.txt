Markdown у README.md — пояснення основних символів

Цей документ пояснює українською мовою основні символи Markdown, які використовуються у README.md для оформлення опису Python-проєкту.

1. Що таке Markdown?

Markdown — це проста мова розмітки, яка дозволяє форматувати звичайний текст: створювати заголовки, списки, жирний текст, курсив, фрагменти коду та блоки коду. Файл README.md зазвичай пишеться саме в Markdown.

2. Символ # — заголовки

Один символ # створює головний заголовок:

# Вибір способу доставки

Два символи ## створюють заголовок другого рівня:

## Опис програми

Можна використовувати також ###, #### та інші рівні. Чим більше символів #, тим нижчий рівень заголовка.

3. Символи ** — жирний текст

Дві зірочки перед і після тексту роблять його жирним.

Приклад: **дуже важливо**

У README це можна використовувати для підкреслення важливої інформації.

4. Символ * — курсив або список

Одна зірочка навколо тексту створює курсив:

Приклад: *важливий текст*

Якщо зірочка стоїть на початку окремого рядка, вона створює пункт маркованого списку:

* сума замовлення

* маса товару

* відстань доставки

5. Символи ` — backtick

Backtick (зворотний апостроф) використовується для виділення короткого фрагмента коду, команди, назви файлу, значення або результату.

Приклад: `самовивіз`

Приклад: `delivery_choice.py`

Backtick відрізняється від звичайного апострофа: ' — апостроф, ` — backtick.

6. Три backticks — блок коду

Три backticks використовуються для створення великого блоку коду або тексту.

Приклад для Python:

```python
amount = 1500
print(amount)
```

Перша трійка ``` відкриває блок, а друга трійка ``` закриває його.

7. Що означає python після ```?

Запис ```python повідомляє Markdown, що всередині блоку знаходиться Python-код. Редактор може завдяки цьому правильно підсвітити синтаксис.

Для звичайного тексту можна написати ```text.

8. Нумерований список

Записи 1., 2., 3. тощо створюють нумерований список.

1. Перевірити дані

2. Перевірити відстань

3. Визначити спосіб доставки

9. Символ \ — зворотний слеш

Зворотний слеш використовується для екранування спеціального символу. Тобто він повідомляє Markdown, що наступний символ потрібно показати буквально, а не використовувати як команду форматування.

Приклад: delivery\_choice.py

У результаті назва файлу відображається як delivery_choice.py.

10. Markdown і Python — це не одне й те саме

Markdown використовується для оформлення README.md. Python використовується для написання самої програми.

Markdown: **важливо**

Python: amount = 1500
