# Вибір способу доставки

## Опис програми

Програма визначає спосіб доставки замовлення залежно від суми замовлення, маси товару, відстані доставки та його крихкості.

Програма **не розраховує вартість доставки**, а лише визначає доступний спосіб доставки.

## Вхідні дані

Користувач вводить:

* суму замовлення у гривнях;
* масу товару в кілограмах;
* відстань доставки в кілометрах;
* чи є товар крихким: `так` або `ні`.

## Правила вибору доставки

Правила перевіряються послідовно. Перше виконане правило визначає результат.

1. Якщо сума від'ємна, маса не є додатною, відстань від'ємна або введено неправильну відповідь про крихкість — `некоректні дані`.
2. Якщо відстань дорівнює `0 км` — `самовивіз`.
3. Якщо товар крихкий і його маса більша за `10 кг` — `звичайна доставка недоступна`.
4. Якщо сума замовлення не менше `1500 грн`, відстань не більше `20 км`, а маса не більше `15 кг` — `безкоштовна кур'єрська доставка`.
5. В інших випадках — `платна кур'єрська доставка`.

## Запуск програми

Для запуску потрібно мати встановлений Python.

У терміналі виконати:

```bash
py delivery_choice.py
```

Після запуску програма попросить ввести необхідні дані.

## Приклад запуску програми

Приклад введення даних:

```text
Сума замовлення, грн: 1500
Маса, кг: 10
Відстань, км: 20
Товар крихкий? (так/ні): ні
```

Результат роботи програми:

```text
безкоштовна кур'єрська доставка
```

У цьому прикладі всі умови для безкоштовної кур'єрської доставки виконані: сума становить `1500 грн`, відстань — `20 км`, маса — `10 кг`.
