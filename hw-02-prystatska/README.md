## Програма обчислює бюджет поїздки туди й назад.

## Користувач вводить:
 відстань в один бік у кілометрах;
 витрату пального на 100 км;
 ціну одного літра пального;
 кількість пасажирів.

## Основні обчислення

Повна відстань:
total_km = distance * 2

Кількість потрібного пального:
fuel_liters = total_km * consumption / 100

Загальна вартість пального:
total_fuel_cost = fuel_liters * fuel_price

Вартість для одного пасажира:
price_per_person = total_fuel_cost / passengers

Кількість повних каністр:
canisters = int(fuel_liters // 20)

Залишок пального:
rest = fuel_liters % 20

Мінімальна кількість каністр:
needed_canisters = canisters + bool(rest)

## Складений вираз

fuel_liters = (total_km * consumption) / 100

Можна записати: 
fuel_liters = total_km * consumption / 100

Порядок обчислення:

Дужки тут не змінюють результат, тому що * і / мають однаковий пріоритет і виконуються зліва направо.

Дужки показують задум: спочатку ми хочемо отримати total_km * consumption, а потім поділити цей результат на 100.


## Оператори для каністр

`//` — цілочисельне ділення. Воно показує, скільки повних каністр по 20 літрів можна заповнити.

`%` — остача від ділення. Вона показує, скільки літрів залишилося після повних каністр.

Наприклад:
24 // 20  # 1
24 % 20   # 4

Отже, для 24 літрів маємо 1 повну каністру і 4 літри залишку. Тому потрібно 2 каністри.

bool(rest) використовується без `if`:

bool(4)  # True
bool(0)  # False

У арифметичному виразі `True` працює як `1`, а `False` — як `0`.

Тому:
needed_canisters = canisters + bool(rest)


## Перевірки

| Перевірка                | Очікуваний результат                                             |
| ------------------------ | ---------------------------------------------------------------- |
| Ціла кількість літрів    | наприклад, 20 л → 1 повна каністра, 0 л залишку                  |
| Дробова кількість літрів | наприклад, 17.1 л → 0 повних каністр, 17.1 л залишку, 1 каністра |
| Точно ділиться на 20     | 40 л → 2 повні каністри, 0 л залишку, 2 каністри                 |
| Є ненульовий залишок     | 24 л → 1 повна каністра, 4 л залишку, 2 каністри                 |

## Публічний приклад

Вхідні дані:

100 км
8 л/100 км
60 грн/л
4 пасажири

Результат:

Повна відстань: 200 км
Потрібно пального: 16 л
Загальна вартість: 960 грн
Вартість для одного пасажира: 240 грн
Повних каністр: 0
Залишок: 16 л
Мінімальна кількість каністр: 1
