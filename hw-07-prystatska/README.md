# Лабораторна робота: Набір утиліт для обчислень (calculation)

Цей проєкт містить бібліотеку математичних та текстових функцій, а також модуль для автоматичного тестування.

## Структура проєкту

`calculation.py` — основний модуль, що містить логіку обчислювальних функцій.
`demo1.py` — тестовий скрипт, який запускає перевірку функцій.
`demo.py` — оптимізований варіант `demo1.py`.

---

## Опис функцій (`calculation.py`)

Модуль містить 5 базових інструментів для роботи з даними:

1. **`mean(*values)`**  
   Обчислює середнє арифметичне одного або кількох чисел. Якщо функцію викликано без аргументів, вона повертає `None`.
2. **`clamp(value, lower, upper)`**  
   Обмежує (втискає) число `value` у задані межі `lower` та `upper`. Якщо порядок меж неправильний (`lower > upper`), функція повертає `None`.
3. **`weighted_sum(values, weights)`**  
   Повертає зважену суму для списку значень та їхніх вагових коефіцієнтів. Повертає `None`, якщо списки порожні або мають різну довжину.
4. **`format_record(title, **fields)`**  
Форматує текстовий запис про об'єкт. Приймає назву об'єкта та довільний набір іменованих характеристик (`kwargs`), виводячи їх у вигляді структурованого рядка.
5. **`factorial(n)`**  
   Рекурсивна функція для обчислення факторіала цілого невід'ємного числа n!.

#### format_record(name, \*\*fields) чому саме тут змінний набір іменованих полів доречний. Пояснення:

Використання синтаксису \*\*kwargs є ідеальним рішенням для цієї функції з кількох причин:
• Гнучкість сутностей: Різні об'єкти мають абсолютно різні набори характеристик. Для студента потрібні поля group та age, для книги — author та pages, а для товару — price та stock.
Функція не повинна знати наперед, який об'єкт вона форматує.
• Масштабованість (Пряма підтримка розширення): Якщо завтра у сутності «Анна» з'явиться нове поле (наприклад, email або hobby), не доведеться переписувати саму функцію format_record чи додавати нові аргументи,
kwargs — словник іменованих аргументів
Вона автоматично опрацює будь-яку кількість нових полів.
• Валідація відсутніх даних: Нам не потрібно передавати значення на кшталт age=None або phone="" для тих об'єктів, у яких цих даних немає (як у випадку з Іваном). Ми просто передаємо те, що є, уникаючи загромадження коду.

#### Ручне трасування factorial(4) до базового випадку

Ручне трасування
Коли ми викликаємо factorial(4), Python використовує стек викликів (Call Stack),
працюючи у два етапи: спочатку занурюється вглиб (прямий хід), а потім повертає значення назад (зворотний хід).
Етап 1: Прямий хід (Занурення в рекурсію)

1. Виклик factorial(4): Перевірка 4 == 1 хибна. Функція чекає на результат виразу: 4 \* factorial(3).
2. Виклик factorial(3): Перевірка 3 == 1 хибна. Функція чекає на результат виразу: 3 \* factorial(2).
3. Виклик factorial(2): Перевірка 2 == 1 хибна. Функція чекає на результат виразу: 2 \* factorial(1).
4. Виклик factorial(1): Базовий випадок спрацював! Перевірка 1 == 1 істинна. Функція миттєво повертає 1.
   Етап 2: Зворотний хід (Згортання стеку з обчисленням)
   • Результат factorial(1) повернувся у factorial(2) \(\rightarrow \) обчислюється 2 _ 1 = 2.
   • Результат factorial(2) повернувся у factorial(3) \(\rightarrow \) обчислюється 3 _ 2 = 6.
   • Результат factorial(3) повернувся у factorial(4) \(\rightarrow \) обчислюється 4 \* 6 = 24.
   Функція завершує роботу і видає кінцевий результат: 24.

#### цикл for (ітеративний підхiд)

n = 4
def factorial_iterative(n):
res = 1
for i in range(2, n + 1):
res \*= i
return res

#### Покроковий розбір роботи циклу для n = 4

1. Початковий стан: Створюється змінна res = 1.
2. Старт циклу: Функція range(2, 5) послідовно генерує числа: 2, 3, 4.
3. Ітерація 1 (i = 2): res множиться на 2 \(\rightarrow \) res = 1 \* 2 = 2.
4. Ітерація 2 (i = 3): res множиться на 3 \(\rightarrow \) res = 2 \* 3 = 6.
5. Ітерація 3 (i = 4): res множиться на 4 \(\rightarrow \) res = 6 \* 4 = 24.
6. Кінець циклу: Числа закінчилися. Функція повертає значення res, яке дорівнює 24.

#### Порівняння рекурсивного та циклічного варіантів (рекурсію із циклом for (ітеративним підходом)):

Критерій | Рекурсивний варіант (factorial) |Циклічний варіант (for i in range)
Код циклу для порівняння | return n _ factorial(n-1) |res = 1; for i in range(2, n+1): res _= i
Елегантність коду |Висока. Код виглядає майже як математична формула факторіала. |Середня. Потребує створення додаткових змінних-лічильників.
Використання пам'яті |Енергомістке. Кожен крок створює новий фрейм у стеку пам'яті |Економне. Пам'ять виділяється лише під одну змінну результату
Швидкодія |Трохи повільніший через постійні виклики функцій. |Швидший, бо процесор ефективно оптимізує цикли.
Обмеження (Ризики) |Має ліміт занурення (RecursionError) при дуже великих n (~1000). |Обмежений лише потужністю комп'ютера та пам'яттю під довгі числа.
