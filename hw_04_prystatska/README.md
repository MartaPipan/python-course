## Опис програми

Програма:

приймає числа від користувача;
завершує введення, коли користувач вводить 0;
рахує додатні та від'ємні числа;
рахує кількість прийнятих ненульових чисел;
обчислює їхню суму;
знаходить мінімальне та максимальне число;
пропускає число 13;
рахує, скільки разів було введено 13;
використовує while, break, continue, if, for та range().

## Вхідні дані

Користувач вводить числа по одному.

Логіка обробки:

Ввести число--> 0 ?  ---> так --> break
                |
                |
                 ----> ні ---> 13 ?--- так ---> count++ ---> continue
                                |
                                |  
                                 -----> ні ---> обробити

## Чому використовується continue, а не pass

continue пропускає решту поточної ітерації:

if number == 13:
    especial_number += 1
    continue

pass нічого не пропускає. Він просто нічого не робить.

Тому pass не може замінити continue у цій програмі.

## Пояснення кожної ітерації
1. Введено 5
5 != 0 → продовжуємо.
5 != 13 → обробляємо.
non_zero → 1
total → 5
це додатне число → count_positive = 1
перше прийняте число → minimum = 5, maximum = 5
2. Введено -2
число приймається;
total = 5 + (-2) = 3;
count_negative = 1;
non_zero = 2;
-2 < 5 → новий мінімум -2;
максимум залишається 5.
3. Введено 13
especial_number збільшується: 0 → 1;
виконується continue;
решта коду цієї ітерації не виконується.
Тому 13 не змінює:
total;
non_zero;
count_positive;
count_negative;
minimum_number;
maximum_number.
4. Введено 7
число приймається;
total = 3 + 7 = 10;
count_positive = 2;
non_zero = 3;
мінімум залишається -2;
7 > 5 → максимум стає 7.
5. Введено 0
виконується break;
цикл while завершується;
значення статистики більше не змінюються.
