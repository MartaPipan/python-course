# sys
# У той час як pathlib повністю замінив старий модуль os у роботі з файлами та папками, модуль sys замінити неможливо. Він залишається унікальним та незамінним інструментом.
Причина проста: pathlib і os працюють із довкіллям (диском, файлами), а sys працює з «серцем» самого Python під час запуску вашого коду (налаштування, пам'ять, інтерпретатор).
Давайте розберемо, які унікальні суперсили має sys, яких немає в інших модулях:

1. Зміна папок пошуку (sys.path) — те, що було у вашому коді

Коли ви пишете import calculations, Python шукає цей файл лише у спеціальному списку папок. Цей список лежить всередині sys.path.
Тільки через sys ви можете сказати програмі: «Гей, якщо не знайдеш функцію поруч, зазирни ще в он ту теку за межами проєкту». Ні os, ні pathlib цього робити не вміють.

2. Читання аргументів з термінала (sys.argv)

Уявіть, що ви написали крутий скрипт для обробки оцінок студентів. Сьогодні ви хочете обробити файл math.csv, а завтра — history.csv.
Замість того, щоб щоразу переписувати шлях всередині коду, ви можете запускати програму через термінал ось так:
bash
python process_data.py math.csv
Use o código com cuidado.
Усередині коду модуль sys миттєво спіймає це ім'я:
python
import sys

# sys.argv[0] — це завжди назва самого скрипта ('process_data.py')
# sys.argv[1] — це перший аргумент, який ми передали ('math.csv')
file_to_open = sys.argv[1] 
print(f"Запуск обробки для файлу: {file_to_open}")
Use o código com cuidado.

3. Миттєва зупинка програми (sys.exit())

Якщо ваш код на самому початку перевірив наявність файлу через pathlib і виявив, що файлу немає (if not csv_path.exists():), продовжувати виконання циклів немає жодного сенсу. Команда sys.exit() — це аварійна кнопка, яка миттєво закриває програму.

4. Контроль версій та платформи

sys точно знає, на якому комп'ютері та на якій версії мови його запустили:
• sys.version — покаже точну версію Python (наприклад, 3.12.2).
• sys.platform — підкаже операційну систему (win32 для Windows, darwin для Mac).

📋 Підсумкове правило для вашої шпаргалки:

• Потрібно створити, знайти, видалити, з'єднати чи прочитати файл/теку? ➡️ Використовуйте pathlib.
• Потрібно підключити сторонню папку з кодом, передати дані через консоль або зупинити програму? ➡️ Використовуйте sys.
# Path.cwd()що таке
Path.cwd() — це команда в Python, яка дізнається точну повну адресу папки, у якій ви зараз перебуваєте і з якої запустили свій скрипт.
Абревіатура CWD розшифровується як Current Working Directory (Поточна робоча директорія).
Аналогія: це як функція «Поділитися геопозицією» в телефоні або рядок адреси вгорі Провідника Windows чи Finder на Mac. Вона каже програмі: «Ми зараз перебуваємо ось тут».

Приклад роботи

Якщо ваш скрипт лежить у папці проєкту на диску C:, то виклик цієї команди поверне повний шлях:
python
from pathlib import Path

# Дізнаємося поточну папку
current_folder = Path.cwd()

print(current_folder) 
# Виведе (наприклад для Windows): C:\Users\User\Projects\my_python_project
# Виведе (наприклад для Mac/Linux): /Users/user/projects/my_python_project
Use o código com cuidado.

Навіщо це потрібно у вашому коді?

python
csv_path = Path.cwd() / "lessons" / "lesson-14" / "students_report.csv"

Використання Path.cwd() дає дві величезні переваги:
1. Код працюватиме на будь-якому комп'ютері (Універсальність):
Вам не потрібно жорстко прописувати шлях на зразок C:\Users\Ivan\Documents\.... Якщо ви скинете свій проєкт другу, у якого диск називається D: або у нього взагалі MacBook, Path.cwd() автоматично підлаштується під його комп'ютер.
2. Магія косої риски (/):
Коли ви берете об'єкт Path.cwd() і ставите після нього знак ділення /, бібліотека pathlib розуміє це не як математичну дію, а як команду зайти всередину папки.
	• Path.cwd() / "lessons" означає: «Взяти поточну папку і зазирнути в папку lessons всередині неї».

💡 Важливий нюанс для початківців:

Поточна папка (Path.cwd()) — це папка, відкрита у вашому терміналі (консолі) в момент запуску коду, а не обов'язково та папка, де фізично лежить файл .py. Тому зазвичай радять відкривати в VS Code саме кореневу (головну) папку всього вашого проєкту, щоб шлях завжди знаходився без помилок.

# cwd  ===  os

Так, у модулі os є точний аналог для цієї команди. Замість Path.cwd() використовують функцію os.getcwd().
Абревіатура означає те саме: get current working directory (отримати поточну робочу директорію).
Ось як це виглядає в коді та чим вони відрізняються:

python
import os
from pathlib import Path

# Варіант з os:
шлях_os = os.getcwd()

# Варіант з pathlib (ваш попередній):
шлях_pathlib = Path.cwd()

print(type(шлях_os))       # Виведе: <class 'str'> (це просто текст)
print(type(шлях_pathlib))  # Виведе: <class 'pathlib.WindowsPath'> (або PosixPath)

# У чому різниця і що краще обрати?

Головна відмінність у тому, що саме повертає команда:
1. os.getcwd() повертає звичайний ТЕКСТ (рядок/string).
Якщо ви захочете додати до нього папки, вам доведеться писати довгу конструкцію з 
os.path.join():

python
csv_path = os.path.join(os.getcwd(), "lessons", "lesson-14", "students_report.csv")

2. Path.cwd() повертає спеціальний ОБ'ЄКТ типу Path.
Це дозволяє використовувати красиву та коротку магію косої риски /:python
csv_path = Path.cwd() / "lessons" / "lesson-14" / "students_report.csv"

Коли ваш шлях є об'єктом Path, ви можете запитувати у нього інформацію напряму:
from pathlib import Path
csv_path = Path("lessons/lesson-14/students_report.csv")
print(csv_path.name)       # 📄 students_report.csv (тільки назва файлу)
print(csv_path.stem)       # 🏷️ students_report (назва без розширення)
print(csv_path.suffix)     # 🔍 .csv (тільки розширення)
print(csv_path.parent)     # 📁 lessons/lesson-14 (папка, де лежить файл)
print(csv_path.exists())   # ❓ True або False (чи існує такий файл фізично)


3. Легке читання та запис файлів

З pathlib не обов'язаково писати with open(...), якщо потрібно просто швидко прочитати або записати весь текст у файл:
python
from pathlib import Path

my_file = Path("hello.txt")

# Швидкий запис тексту у файл (створить файл автоматично):
my_file.write_text("Привіт, Python!", encoding="utf-8")

# Швидке читання всього вмісту:
print(my_file.read_text(encoding="utf-8"))  # Виведе: Привіт, Python!
