### Рекурсія у програмуванні — це процес, коли функція викликає сама себе для розв'язання меншої частини тієї ж самої задачі.
Щоб така функція не працювала нескінченно, її структура обов'язково має складатися з двох компонентів.
Дві головні частини рекурсії
• Базовий випадок (Base case): Умова зупинки. Коли задача стає мінімальною, функція повертає конкретне значення без нового виклику себе. Без цього виникне помилка переповнення стека.
• Рекурсивний крок (Recursive step): Дія, під час якої функція викликає сама себе, але з трохи меншими або простішими вхідними даними, наближаючись до базового випадку.


Класичний приклад: Факторіал числа
Факторіал числа 5 (5!) — це добуток 5 × 4 × 3 × 2 × 1. Рекурсивно це записується так:
python
def factorial(n):
    # 1. Базовий випадок (умова виходу)
    if n == 1 or n == 0:
        return 1
    
    # 2. Рекурсивний крок (виклик самої себе)
    return n * factorial(n - 1)

print(factorial(5))  # Виведе: 120


Як це працює у пам'яті
Кожен виклик функції додає новий шар у пам'ять комп'ютера (так званий стек викликів).
1. factorial(5) чекає на результат factorial(4).
2. factorial(4) чекає на factorial(3), і так далі, аж до factorial(1).
3. Коли досягається базовий випадок (1), результати починають «підійматися» назад, перемножуючись на кожному кроці.
Обмеження рекурсії в Python
Python має захист від зациклення — максимальну глибину рекурсії (за замовчуванням це 1000 викликів). Якщо перевищити цей ліміт, програма зупиниться з помилкою RecursionError: maximum recursion depth exceeded. У більшості практичних завдань звичайні цикли for або while працюють безпечніше та ефективніше за рекурсію.
Якщо бажаєте, ми можемо розібрати:
### • Приклад рекурсії для обходу вкладених списків або папок
def print_nested_list(elements):
    for element in elements:
        # 1. Базовий випадок: якщо елемент — це просто число/рядок (не список)
        if not isinstance(element, list):
            print(f"Знайдено елемент: {element}")
            
        # 2. Рекурсивний крок: якщо елемент виявився СПИСКОМ
        else:
            print("--- Заходимо на рівень глибше ---")
            print_nested_list(element)  # Функція викликає сама себе для вкладеного списку
            print("--- Повертаємося назад ---")

# Складний вкладений список (має 3 рівні вкладеності)
matrix = [1, [2, 3], [4, [5, 6], 7], 8]

# Запуск функції
print_nested_list(matrix)


### Як це працює покроково:
1. Функція починає обходити головний список matrix. Бачить число 1, перевіряє через isinstance(element, list) — це не список, тому просто виводить 1.
2. Наступний елемент — це список [2, 3]. Умова if не спрацьовує, ми йдемо в else. Функція ставить головний список "на паузу" і запускає нову копію самої себе для списку [2, 3].
3. Всередині виводяться 2 і 3. Цей внутрішній цикл завершується, копія функції закривається, і ми повертаємося до головного списку.
4. Далі йде елемент [4, [5, 6], 7]. Функція знову занурюється всередину, виводить 4, потім бачить ще один список [5, 6], занурюється ще на один рівень глибше, виводить їх, і поступово повертається назад.
