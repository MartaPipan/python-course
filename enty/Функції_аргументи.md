### 1. Позиційні, іменовані та стандартні аргументи
У Python є кілька способів передати дані (аргументи) у функцію. Давайте розберемо їх на основі вашого коду:
python
def format_student(name, group, active=True):
    status = "активний" if active else "неактивний"
    return f"{name}, {group}, {status}"

## • Позиційні аргументи (За порядком):python
print(format_student("Олена", "КН-11"))

Комп'ютер дивиться на порядок: перше слово "Олена" автоматично потрапляє в перший параметр name, а друге "КН-11" — у другий параметр group.
### • Іменовані аргументи (За назвою):python
print(format_student(group="КН-12", name="Марко", active=False))

Тут ми чітко кажемо: «Це для group, а це для name». У такому разі порядок не має значення — ви можете міняти їх місцями як завгодно, і Python не заплутається.
### • Стандартні аргументи (Default values):
У визначенні функції ми написали active=True. Це значення за замовчуванням. Якщо під час виклику функції ми забудемо або не схочемо вказати цей параметр (як у випадку з Оленою), Python сам підставить True.
⚠️ Важливе правило: Параметри зі стандартними значеннями (як active=True) обов'язково мають стояти в самому кінці списку параметрів. Написати def format_student(active=True, name, group) — заборонено, код видасть помилку.

 ### 2. Головна пастка: Змінювані об'єкти (списки) як стандартні значення
Це одна з найвідоміших помилок у Python, на якій ловляться навіть досвідчені розробники.
### ❌ ЯК РОБИТИ НЕ ТРЕБА:
python
def add_task(task, tasks=[]):  # ❌ Список [] створено ОДИН РАЗ під час дефініції функції
    tasks.append(task)
    return tasks

print(add_task("Почитати книгу"))  # Виведе: ['Почитати книгу']
print(add_task("Помити посуд"))    # Виведе: ['Почитати книгу', 'Помити посуд'] 😱

Чому так сталося? Python створює стандартний список [] лише один раз — коли бачить слово def.
 При повторних викликах функції вона не створює новий порожній список, а продовжує використовувати той самий старий,
  накопичуючи в ньому дані («пам'ять» між викликами).

### ЯК РОБИТИ ПРАВИЛЬНО (Використовуємо None):
python
def add_task(task, tasks=None):  #  Використовуємо безпечний незмінний None
    if tasks is None:
        tasks = []               #  Новий порожній список створюється ЩОРАЗУ під час виклику функції
    tasks.append(task)
    return tasks

print(add_task("Почитати книгу"))  # Виведе: ['Почитати книгу']
print(add_task("Помити посуд"))    # Виведе: ['Помити посуд'] — Тепер усе працює правильно!

### 3. Що таке *args та **kwargs?
Це спеціальні інструменти для випадків, коли ви наперед не знаєте, скільки саме аргументів користувач передасть у функцію.
### • *args (Зірочка для позиційних аргументів):
Збирає всі «зайві» передані аргументи у один кортеж (tuple). Потрібен, коли кількість однотипних даних постійно змінюється.python
# Функція приймає будь-яку кількість чисел і додає їх  (*args)
def sum_numbers(*args):
    return sum(args)  # args всередині є кортежем, наприклад (1, 2, 3)

print(sum_numbers(1, 2))        # Виведе: 3
print(sum_numbers(1, 2, 3, 4))  # Виведе: 10
Use o código com cuidado.

### • **kwargs (Дві зірочки для іменованих аргументів):
Збирає всі «зайві» іменовані аргументи (параметри у форматі ключ=значення) у один словник (dict).python
# Функція приймає будь-які характеристики студента (**kwargs)
def show_student_info(**kwargs):
    # kwargs всередині є словником, наприклад {"name": "Іван", "age": 20}
    for key, value in kwargs.items():
        print(f"{key}: {value}")

show_student_info(name="Іван", age=20, city="Київ")

 ### Коли потрібні *args та **kwargs?
Використовуйте їх тільки тоді, коли ви заздалегідь не знаєте точну кількість елементів, які передасть користувач.
Інструмент	Що робить?	Тип даних всередині	Приклад виклику
*args	Збирає «зайві» аргументи за порядком	Кортеж (tuple)	sum_numbers(1, 2, 3, 4, 5)
**kwargs	Збирає «зайві» іменовані аргументи	Словник (dict)	show_info(age=20, city="Київ")

### Шпаргалка: Області видимості змінних (Scopes)
В Python діє правило LEGB (Local ➔ Enclosing ➔ Global ➔ Built-in), за яким комп'ютер шукає змінні знизу вгору.
### 1. Локальна (local) та Глобальна (global) області
python
x = "Глобальна"  # Живе в усьому файлі

def func():
    y = "Локальна"   # Живе ТІЛЬКИ всередині цієї функції
    print(y)         #  Працює
    print(x)         #  Працює (читати глобальну змінну можна вільно)

func()
# print(y)  # ❌ ПОМИЛКА! Код ззовні не бачить локальну змінну y

### 2. Ключове слово global (Зміна ззовні)
Якщо всередині функції потрібно змінити глобальну змінну, обов'язково використовуйте префікс global. Без нього Python просто створить нову одноіменну локальну змінну, не зачіпаючи глобальну.
python
score = 0  # Глобальна змінна

def add_points():
    global score  # Кажемо: "Працюємо з оригінальною змінною score ззовні"
    score += 10

add_points()
print(score)  # Виведе: 10 (значення успішно змінилося)

### 3. Ключове слово nonlocal (Вкладені функції)
Використовується у вкладених функціях (функція всередині іншої функції). Воно дозволяє змінити змінну, яка лежить у «батьківській» функції, але не є глобальною.
python
def outer_func():
    msg = "Привіт"  # Змінна для outer_func (Enclosing scope)
    
    def inner_func():
        nonlocal msg  # Дозволяє змінити msg батьківської функції
        msg = "Бувай"
        
    inner_func()
    print(msg)  # Виведе: "Бувай" (значення змінилося!)

outer_func()

### 📊 Коротке порівняння
### Ключове слово	Що воно робить?	Коли застосовувати?
### global	Зв'язує змінну з найвищим рівнем файлу	Коли функція має оновити глобальний лічильник або налаштування.
### nonlocal	Зв'язує змінну з рівнем вище (але не глобальним)	Використовується переважно у замиканнях (closures) та фабриках функцій.
