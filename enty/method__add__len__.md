«Магічні» методи (англійською Dunder methods, від Double Under score — подвійне підкреслення) — це спеціальні вбудовані методи в Python, які починаються і закінчуються двома знаками підкреслення.
Вони потрібні для того, щоб навчити ваші власні об'єкти реагувати на стандартні оператори та функції Python, такі як +, -, len(), == тощо.
Коли ви використовуєте знак + або викликаєте функцію len(), Python «за лаштунками» автоматично шукає та викликає відповідний магічний метод всередині об'єкта.
Давайте розберемо два найпопулярніших методи: __len__ та __add__.

1. Метод __len__ (Вчимо об'єкт рахуватися)

Коли ви викликаєте стандартну функцію len(об'єкт), Python насправді виконує команду об'єкт.__len__().
• Навіщо це потрібно? Для рядків або списків Python уже знає, як рахувати довжину. Але якщо ви створили свій клас, наприклад Group (Група студентів), Python без вашої допомоги не знатиме, що саме вважати довжиною групи — кількість студентів, кількість стільців чи довжину назви.

class Group:
    def __init__(self, title):
        self.title = title
        self.students = []  # Список студентів групи

    def add_student(self, student_name):
        self.students.append(student_name)

    # Реалізуємо магічний метод __len__
    def __len__(self):
        return len(self.students)  # Довжиною групи вважаємо кількість студентів

# Створюємо групу
kn11 = Group("КН-11")
kn11.add_student("Олена")
kn11.add_student("Данило")

# Тепер ми можемо використовувати стандартну функцію len()!
print(len(kn11))  # Виведе: 2



2. Метод __add__ (Вчимо об'єкти додаватися через +)

Коли ви пишемо в коді x + y, Python насправді перетворює це на виклик типу x.__add__(y).
• Навіщо це потрібно? За замовчуванням Python вміє додавати числа (5 + 3 = 8) або склеювати рядки ("а" + "б" = "аб"). Але якщо ви спробуєте додати через + два власні об'єкти, Python видасть помилку TypeError. Метод __add__ дозволяє вам особисто визначити, що має статися під час натискання на «плюс».

💻 Приклад у коді:

Уявімо, що ми пишемо гру, де є Кошики з золотом, і хочемо додавати один кошик до іншого, щоб отримати новий великий кошик.
python
class Pouch:
    def __init__(self, gold):
        self.gold = gold

    # Реалізуємо магічний метод __add__
    # self — це лівий об'єкт від знака +, other — це правий об'єкт
    def __add__(self, other):
        if isinstance(other, Pouch):
            # Повертаємо НОВИЙ кошик із сумою золота двох попередніх
            return Pouch(self.gold + other.gold)
        raise TypeError("Можна додавати лише кошик до кошика!")

    # Додамо вже знайомий __repr__, щоб гарно бачити результат
    def __repr__(self):
        return f"Pouch(gold={self.gold})"

# Створюємо два кошики
pouch1 = Pouch(50)
pouch2 = Pouch(30)

# Магія! Тепер працює звичайний оператор плюса:
pouch3 = pouch1 + pouch2

print(pouch3)  # Виведе: Pouch(gold=80)

 Назва __repr__ походить від слова Representation (представлення).
Його головна мета — показати розробнику текстовий вигляд об'єкта, який максимально точно описує, як цей об'єкт влаштований. Це інструмент виключно для програмістів, який використовується під час дебагу (налагодження), діагностики помилок та виведення в консоль чи лог-файли.
Ось базовий шаблон, який вважається золотим стандартом у Python:
python
def __repr__(self):
    return f"НазваКласу(атрибут1={self.атрибут1!r}, атрибут2={self.атрибут2!r})"
Use o código com cuidado.

💡 Головні фішки, які варто пам'ятати:

1. Прапорець !r: Коли ти пишеш {self.name!r}, Python автоматично виведе рядок у лапках (наприклад, 'Олена'). Це одразу підказує у терміналі, що тип даних — саме рядок (str).
2. Ідеальний стандарт: Хороший __repr__ має повертати такий рядок, який можна буквально скопіювати, вставити в код і заново створити точно такий самий об'єкт.
3. Безпека понад усе: Ніколи не виводь у __repr__ паролі, токени або номери карт. Якщо програма впаде, ці дані автоматично запишуться в текстові логи сервера, що є серйозною дірою в безпеці.

💻 Швидкий приклад для згадки:

python
class Student:
    def __init__(self, name, group):
        self.name = name
        self.group = group

    # Наш магічний метод для діагностики
    def __repr__(self):
        return f"Student(name={self.name!r}, group={self.group!r})"

student = Student("Данило", "КН-11")

# Коли ми дивимося на об'єкт у списку (або під час дебагу):
print([student])  
# Виведе чітко й зрозуміло: [Student(name='Данило', group='КН-11')]
