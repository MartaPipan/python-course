set — множина
numbers = {1, 2, 3}
Метод	Що робить
.add(x)	додає елемент
.remove(x)	видаляє елемент
.discard(x)	видаляє без помилки, якщо немає елементa
.remove() на відсутньому елементі спричиняє KeyError, discard() — ні.
.pop()	видаляє випадковий/довільний елемент
.clear()	очищає
.union()	об'єднання
.intersection()	спільні елементи
.difference()	різниця
.issubset()	перевіряє, чи є підмножиною
.issuperset()	перевіряє, чи містить іншу множину

Наприклад:

a = {1, 2, 3}
b = {3, 4, 5}

a.union(b)         # {1,2,3,4,5}
a.intersection(b)  # {3}
a.difference(b)    # {1,2}


Метод	Що робить
.get(key)	отримує значення
.keys()	отримує всі ключі
.values()	отримує всі значення
.items()	отримує ключ + значення
.update()	додає/оновлює дані
.pop(key)	видаляє ключ
.popitem()	видаляє останню пару
.clear()	очищає словник
.copy()	копіює словник
Найчастіше:
person.get("name")
person.keys()
person.values()
person.items()
person.update({"city": "Adenau"})


###  основні математичні операції з множинами (set) у Python.
lecture = {"Олена", "Марко", "Ірина"}
practice = {"Марко", "Ірина", "Тарас"}

print(lecture | practice) # об'єднання
print(lecture & practice) #перетин
print(lecture-practice) # лише на лекції
print(lecture ^ practice) # лише в одній множині
