### Шпаргалка: Безпечна робота зі словниками в Python
1. dict["key"] vs dict.get("key")
Спосіб	Що станеться, якщо ключа немає?	Коли використовувати?
student["id"]	❌ Викличе помилку KeyError (програма зламається)	Коли поле є обов'язковим (наприклад, id, name). Його відсутність — це брак даних.
student.get("email")	Поверне None або значення за замовчуванням	Коли поле є необов'язковим (наприклад, email, phone). Програма продовжить роботу.


student = {"name": "Іван", "id": 101}
# 1. Ключа немає — повертає None (помилки немає)
email = student.get("email")  # Результат: None
# 2. Ключа немає — повертає наше дефолтне значення
status = student.get("status", "активний")  # Результат: "активний"
# 3. Ключ Є — повертає значення зі словника (дефолтне ігнорується)
name = student.get("name", "Анонім")  # Результат: "Іван"


### . Головна пастка: Перевірка ключів та 0 (Нуль) ❌ ЯК РОБИТИ НЕ ТРЕБА (Помилка з нулем):
student = {"name": "Олена", "score": 0}
# Python вважає 0 за False! 
if student.get("score"):  
    print("Ура, оцінка є!")
else:
    print("Оцінки немає!")  # ❌ Виведе це! Хоча оцінка є — це 0.


### ЯК РОБИТИ ПРАВИЛЬНО (Перевірка через in): !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
student = {"name": "Олена", "score": 0}
# Перевіряє факт наявності КЛЮЧА, а не його значення
if "score" in student:  
    print(f"Оцінка існує в базі: {student['score']}")  #  Виведе це (0)    




###   Головне правило безпеки: Зміна розміру словника
❌ ЯК РОБИТИ НЕ ТРЕБА (Програма зламається):
Неможливо додавати або видаляти ключі безпосередньо під час обходу словника.
python
# Викличе помилку RuntimeError: dictionary changed size during iteration
for key in student:
    if key == "age":
        del student[key]  # ❌ Спроба видалити ключ всередині циклу
Use o código com cuidado.
ЯК РОБИТИ ПРАВИЛЬНО (Через list()):
Щоб безпечно видаляти чи додавати ключі, загорніть словник у list(). Це створить незалежну копію ключів у пам'яті.
python
# Безпечне видалення ключів
for key in list(student):  #  Робимо злімок ключів
    if key == "age":
        del student[key]  # Тепер помилки не буде!





Два способи обходу (ітерації) словника в циклі for
У коді показано два варіанти, як перебрати всі елементи словника. Вони роблять одне й те саме, але записуються по-різному:
• Варіант 1 (Тільки через ключі):python
for key in student:
    print(key, student[key])

Коли ми пишемо for key in student, Python за замовчуванням перебирає лише ключі словника. Щоб отримати значення, нам доводиться всередині циклу звертатися до словника за цим ключем: student[key].
• Варіант 2 (Одразу ключ і значення — рекомендується):python
for key, value in student.items():
    print(key, value)
Метод .items() повертає пари «ключ-значення». Завдяки розпакуванню ми одразу отримуємо і ключ у змінну key, і його значення у змінну value. Це чистіший і швидший спосіб.
Головне правило безпеки: Не змінюйте розмір словника в циклі!
«Не змінюйте розмір словника під час прямого обходу; за потреби перебирайте list(student)»
• У чому небезпека: Якщо всередині циклу for ви спробуєте додати новий ключ або видалити існуючий, Python миттєво зламається з помилкою: RuntimeError: dictionary changed size during iteration. (Змінювати значення існуючих ключів можна, а от додавати/видаляти самі ключі — заборонено).
• Як це обійти: Якщо вам дійсно потрібно видалити якісь ключі під час циклу, перетворіть ключі словника на звичайний список за допомогою list(student). Список створює статичний злімок (копію) ключів у пам'яті, який вже не пов'язаний динамічно зі словником.
Приклад обходу «безпечним» шляхом:
python
# Видаляємо всі ключі, які починаються на "test"
for key in list(student):  # list() робить копію ключів !!!!!!
    if key.startswith("test"):
        del student[key]   # Тепер помилки не буде!




### Генератори словників (dict comprehensions) — це компактний і швидкий спосіб створення нових словників на основі існуючих списків, кортежів чи інших словників в один рядок коду.
Синтаксис виглядає так: {ключ: значення for елемент in послідовність if умова}



Підрахунок частот елементів у Python
1. Класичний метод: dict.get(key, 0) + 1
Найпопулярніший спосіб, який замінює довгі конструкції if-else. Він дозволяє безпечно додавати нові елементи та оновлювати лічильники існуючих в один рядок.
python
words = ["python", "java", "python", "c++", "java", "python"]
frequency = {}

for word in words:
    # Якщо слова немає — береться 0 і додається 1. 
    # Якщо слово є — береться його поточна кількість і додається 1.
    frequency[word] = frequency.get(word, 0) + 1

# Результат: {'python': 3, 'java': 2, 'c++': 1}
print(frequency)
Use o código com cuidado.
Як це працювало б через if-else (довгий шлях):
python
# Цей код робить ТЕ САМЕ, але займає більше місця:
for word in words:
    if word in frequency:
        frequency[word] += 1
    else:
        frequency[word] = 1

2. Сучасний супершвидкий метод: Counter
В Python є вбудований інструмент у модулі collections, створений спеціально для цього завдання. Він робить усе автоматично в один рядок без жодних циклів for.
python
from collections import Counter

words = ["python", "java", "python", "c++", "java", "python"]

# Передаємо список прямо у Counter
frequency = Counter(words)

# Результат: Counter({'python': 3, 'java': 2, 'c++': 1})
print(frequency)

# З ним працюють усі звичні методи словників:
print(frequency["python"])  # Виведе: 3
Use o código com cuidado.
Додаткова перевага Counter: Він має крутий метод .most_common(N), який миттєво повертає N найпопулярніших елементів:
python
# Знайти топ-2 найчастіших слів
print(frequency.most_common(2))  # Результат: [('python', 3), ('java', 2)]
Use o código com cuidado.
