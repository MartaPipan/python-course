Кортежі використовуються для зберігання кількох елементів в одній змінній.
Кортеж — це впорядкована та незмінна колекція .

Створення: Використовуються круглі дужки () або функція tuple().
Для створення кортежу з одного елемента обов'язково потрібна кома: (1,).


tuple — кортеж
Схожий на list, але його не можна змінити.



# З кортежу у список (щоб змінити дані)
my_tuple = (1, 2, 3)
my_list = list(my_tuple)  # Результат: [1, 2, 3]

# З списку у кортеж (щоб зафіксувати дані)
my_list2 = [4, 5, 6]
my_tuple2 = tuple(my_list2)  # Результат: (4, 5, 6)

Найпростіша асоціація:

list — багато речей по порядку
tuple — багато речей, які не змінюємо
set — багато унікальних речей
dict — інформація з назвами полів

### Методи кортежів
Python має два вбудовані методи, які можна використовувати для кортежів.

numbers = (1, 2, 3)
print(numbers.count(2))	рахує, скільки разів число 2 зустрічається в кортежі.
print(numbers.index(3))	шукає порядковий номер (індекс) елемента 3
