Списки створюються за допомогою квадратних дужок
Списки використовуються для зберігання кількох елементів в одній змінній.


Запам'ятай
str   → текст
list  → список, можна змінювати
tuple → список, не можна змінювати
set   → тільки унікальні значення
dict  → ключ → значення

Найпростіша асоціація:

list — багато речей по порядку
tuple — багато речей, які не змінюємо
set — багато унікальних речей
dict — інформація з назвами полів


Функція list()створює об'єкт списку.

Об'єкт списку — це впорядкована та змінна колекція.

list — список

Зберігає кілька значень у певному порядку.

numbers = [10, 20, 30]
має індекси: numbers[0]
можна змінювати
можна додавати: .append()
можна видаляти: .remove(), .pop()

👉 Використовуй, коли потрібен змінюваний список.


numbers = [1, 2, 3]

Метод	Що робить
.append(x)	додає x в кінець
.insert(i, x)	додає x на позицію i
.extend(...)	додає кілька елементів
.remove(x)	видаляє перше x
.pop()	видаляє останній елемент
.pop(i)	видаляє елемент за індексом
.clear()	очищає список
.index(x)	знаходить індекс x
.count(x)	рахує x
.sort()	сортує список
.reverse()	перевертає список
.copy()	створює копію
Часто використовуються:
numbers.append(4)
numbers.remove(2)
numbers.sort()
