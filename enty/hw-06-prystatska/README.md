### 6. Використані вбудовані структури, методи та функції в коді 

У цьому проєкті використовуються базові вбудовані методи та функції Python для роботи зі списками, словниками, множинами та обчисленнями.

#### 1. Методи для роботи зі списками (list methods)
*   **`.append(element)`**
    *   *Пояснення:* Додає елемент у самий кінець списку. Цей метод змінює оригінальний список на місці (мутує його).
    *   *Де використовується:*
        *   `duplicates_list.append(current_best)` — для збереження відкинутих копій студентів.
        *   `target_student_new["scores"].append(99)` — для додавання нової оцінки в тесті на залежність пам'яті.
*   **`.copy()`**
    *   *Пояснення:* У активній версії коду виконується копіювання словників через генератор списків `student.copy()`. Оскільки внутрішній рівень (списки оцінок) не копіюється повторно, створюється **поверхнева копія** (*shallow copy*). Обидва словники посилаються на один і той самий список `scores` в пам'яті, що унаочнює концепт взаємозв'язку даних.
    *   *Примітка:* В альтернативному (закоментованому) коді метод `.copy()` викликається двічі (для словника і додатково для вкладеного списку `student["scores"].copy()`), що демонструє створення повної незалежної копії даних.

#### 2. Методи для роботи з множинами (set methods)
*   **`.add(element)`**
    *   *Пояснення:* Додає новий елемент до множини. Якщо такий елемент уже існує, множина не зміниться (оскільки вона зберігає лише унікальні значення).
    *   *Де використовується:* `checked_ids.add(student_id)` — для реєстрації вже оброблених ID під час реконструкції списку (захист від повторного додавання дублікатів).

#### 3. Методи для роботи зі словниками (dict methods)
*   **`.get(key)`**
    *   *Пояснення:* Безпечно шукає елемент у словнику за ключем (`key`). Головна перевага над стандартним записом `dict[key]` полягає в тому, що якщо ключа немає в словнику, метод не ламає програму помилкою `KeyError`, а просто повертає значення `None`.
    *   *Де використовується:* `student_by_id.get(known_id)` та `.get(unknown_id)` — для безпечної перевірки наявності студента в базі за його ідентифікатором без ризику падіння програми.

#### 4. Вбудовані функції 
*   **`len(collection)`**
    *   *Пояснення:* Повертає кількість елементів (довжину) у будь-якій структурі даних (списку, словнику, множині або кортежі).
    *   *Де використовується:* `len(student["scores"])` — для порівняння кількості оцінок у дублікатів, а також для розрахунку середнього балу.
*   **`sum(iterable)`**
    *   *Пояснення:* Математична функція, яка додає (сумує) всі числові елементи всередині списку чи кортежу.
    *   *Де використовується:* `sum(scores)` — для отримання загальної суми балів студента перед діленням.
*   **`sorted(iterable)`**
    *   *Пояснення:* Сортує елементи структури даних за зростанням (або за алфавітом, якщо це рядки) і завжди повертає новий відсортований список, не змінюючи початковий об'єкт.
    *   *Де використовується:* `sorted(list(groups_set))` — для виведення назв студентських груп у гарному алфавітному порядку.

> **Додатково:** У коді використовуються швидкі однорядкові цикли (генератори / comprehensions):
> * `student_by_id = {student["id"]: student for student in students_data}` — автоматично генерує словник для швидкого пошуку.
> * `groups_set = {student["group"] for student in students_data}` — миттєво збирає унікальні групи, автоматично фільтруючи повтори.

## Роль структур даних у проєкті

У цьому проєкті кожна вбудована структура даних Python виконує свою унікальну архітектурну роль, забезпечуючи швидкість та надійність програми:

*   **`list` (Список / `[]`):** 
    *   *Роль:* Використовується для загального журналу `students_data` та вкладеного поля `scores`.
    *   *Чому саме він:* Списки є впорядкованими та дозволяють зберігати дублікати елементів. Це критично для оцінок, оскільки студент може отримати однакові бали (наприклад, дві дев'ятки) за різні самостійні роботи.
*   **`tuple` (Кортеж / `()`):** 
    *   *Роль:* Використовується як унікальний ідентифікатор студента `id: (group, journal_number)`.
    *   *Чому саме він:* Кортежі є незмінними (*immutable*). Це гарантує, що "паспортні" дані студента не будуть випадково змінені під час виконання коду. Технічно, через свою незмінність кортеж є хешованим об'єктом, що дозволяє використовувати його як унікальний ключ у словниках.
*   **`dict` (Словник / `{}`):** 
    *   *Роль:* Представляє саму картку студента, а також структуру швидкого пошуку `student_by_id`.
    *   *Чому саме він:* Забезпечує миттєвий пошук інформації за схемою `Ключ -> Значення` за асимптотичний час \(O(1)\). Завдяки словнику `filtered_list`, ми можемо швидко виявляти та відсікати дублікати за їхніми унікальними ID.
*   **`set` (Множина / `set()`):** 
    *   *Роль:* Використовується для збору унікальних груп `groups_set` та відстеження доданих студентів `checked_ids`.
    *   *Чому саме вона:* Множини зберігають лише унікальні елементи та автоматично ігнорують будь-які повтори під час спроби додавання нових значень.

### Швидкий зв'язок структури та змінної:
*   **`[]` (Список / List):** `students_data` — зберігає послідовність та черговість студентів.
*   **`{}` (Словник / Dict):** `filtered_list` — використовує унікальний `id` як ключ для миттєвого пошуку та відсікання дублікатів.
*   **`set()` (Множина / Set):** `checked_ids` — зберігає унікальні значення, захищає від повторного додавання елементів під час реконструкції журналу за оригінальним порядком.
*   **`()` (Кортеж / Tuple):** `id: ("AB-123", 1)` — незмінний об'єкт. Використовується як ключ для словника, оскільки його не можна випадково модифікувати в пам'яті комп'ютера.

## Втрата інформації за невдалої заміни структур 

Проєкт накладає суворе обмеження: **не можна міняти типи структур між собою**, оскільки це призведе до критичної втрати або пошкодження даних.

### 1. Якщо замінити `scores: list` на `scores: set` (Список на Множину):
*   **Наслідок:** Відбудеться **втрата повторних балів**. 
*   **Приклад:** У студента Ann Smith оригінальний список оцінок виглядає як `[90, 85, 100, 90]`. Якщо конвертувати його в множину `set`, дублікат оцінки `90` буде безповоротно видалений комп'ютером, і структура перетвориться на `{85, 90, 100}`. Середній бал порахується неправильно.

### 2. Якщо замінити `id: tuple` на `id: list` (Кортеж на Список):
*   **Наслідок:** Програма видасть критичну помилку **`TypeError: unhashable type: 'list'`** і повністю зупинить свою роботу.
*   **Приклад:** Списки є змінними об'єктами. В Python заборонено використовувати змінні об'єкти як ключі словника, оскільки їхній внутрішній вміст може змінитись, що зруйнує цілісність таблиці хешування.

### 3. Якщо для дедуплікації використати лише `set(students_data)` (Спробувати очистити список напряму):
*   **Наслідок:** Словники є нехешованими об'єктами. Спроба кинути список словників у `set()` викличе помилку `TypeError: unhashable type: 'dict'`. Крім того, навіть якби це працювало, множина повністю знищила б оригінальний порядок розташування елементів у журналі, оскільки елементи в `set` не мають чітких індексів.
