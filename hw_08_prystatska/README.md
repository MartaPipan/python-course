# Домашня робота 8: Модулі, пакети та віртуальне середовище

Цей проєкт демонструє базову структуру пакетів у Python на прикладі модуля `study_tools`, що містить математичні функції та інструменти форматування звітів. 
Проєкт запускається через головний файл `demo.py`, який захищено конструкцією `if __name__ == "__main__":`.

Проєкт використовує виключно вбудовані можливості Python і не потребує встановлення зовнішніх пакетів.

##  Структура проєкту та призначення файлів

hw_08_prystatska/
├── study_tools/
│   ├── __init__.py
│   ├── calculations.py
│   └── formatting.py
├── demo.py
├── .gitignore
└── README.md

*   **`study_tools/`** — головна папка пакета. Завдяки файлу `__init__.py` всередині, Python сприймає цю директорію як цілісну бібліотеку, яку можна імпортувати в інші скрипти.
  *   **`__init__.py`** — обов'язковий файл для ініціалізації пакета. Він вказує Python, що папка є пакетом, та керує публічним інтерфейсом модуля (експортом функцій).
  *   **`__main__.py`** — файл, що дозволяє запускати весь пакет як самостійну програму з консолі за допомогою команди `python -m study_tools`.
  *   **`calculations.py`** — модуль, який містить логіку математичних чи логічних розрахунків.
              ** (*values): означає пакування аргументів. Він дозволяє функції приймати будь-яку кількість аргументів через кому. 
                            Усередині функції всі ці числа автоматично пакуються в один кортеж (tuple) з ім'ям values. 
  *   **`formatting.py`** — модуль, що містить функції для стилізації та форматування виводу даних чи звітів.
  *   **`__pycache__/`** — службова папка із відкомпільованим байт-кодом (`.pyc`) для прискорення повторних запусків програми (ігнорується Git).
*   **`.gitignore`** — текстовий файл, який вказує системі Git, які файли та папки (наприклад, `.venv` та `__pycache__`) не потрібно відстежувати та додавати до репозиторію.
*   **`demo.py`** — головний демонстраційний скрипт. Він імпортує інструменти з пакета `study_tools` та демонструє їхню роботу.
*   **`README.MD`** — цей файл із документацією до проєкту.

## Інструкція із запуску (для Windows / PowerShell)

Для запуску проєкту та ізоляції середовища виконайте такі команди в терміналі з кореня папки проєкту (`hw_08_prystatska`):

1. **Створити локальне віртуальне середовище `.venv`:**
   python -m venv .venv
  
2. **Активувати віртуальне середовище:**
   .\.venv\Scripts\Activate.ps1

3. **Запустити демонстраційний скрипт `demo.py`:**
   python demo.py

4. **Вийти з віртуального середовища після завершення роботи:**
   deactivate
5. **Як правильно дізнатися поточну папку? Present Working Directory — теперішня робоча папка**
   pwd

автоматично ігноруються системою контролю версій Git завдяки файлу `.gitignore`.
