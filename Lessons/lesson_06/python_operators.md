Comparison operators
 Оператори порівняння в Python 


  Порівняння повертає логічне значення
Запис Запитання звичайною мовою
a == b чи значення рівні?
a != b чи значення різні?
a < b чи a менше?
a <= b чи a менше або дорівнює?
a > b чи a більше?
a >= b чи a більше або дорівнює?


     Оператор               	Значення	                                                   Приклад
>	            Більше того, що - Вірно, якщо лівий операнд більший за правий                	x > y
<	            Менше цього — Правда, якщо лівий операнд менший за правий	                    x < y
==	            Дорівнює - Істинно, якщо обидва операнди рівні	                                x == y
!=	            Не дорівнює - Вірно, якщо операнди не рівні	                                    x != y
>=	            Більше або дорівнює - Істинно, якщо лівий операнд більший або дорівнює правому	x >= y
<=	            Менше або дорівнює - Істинно, якщо лівий операнд менший або дорівнює правому	x <= y




Логічні оператори — це оператори , , . and   or    not
Operator	Meaning	Example
and	        True  if both the operands are true	                    x and y
or	        True  if either of the operands is true                	x or y
not        	True  if operand is false (complements the operand)	    not x
x = True
y = False
print('x and y is',x and y)
print('x or y is',x or y)
print('not x is',not x)
