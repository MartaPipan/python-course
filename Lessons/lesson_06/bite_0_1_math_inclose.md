0.1 + 0.2

має дати:

0.3

Але комп'ютер зберігає числа типу float у двійковій системі — за допомогою 0 і 1.

Проблема в тому, що деякі десяткові дроби неможливо точно представити в двійковій системі.

Тому Python фактично отримує щось дуже близьке до:

0.30000000000000004

print(0.1 + 0.2 == 0.3)

отримаємо:

False

Хоча математично ми очікуємо True.

math.isclose() — приблизне порівняння

Що робить isclose()?

Вона перевіряє не:«Чи абсолютно однакові ці числа?» а «Чи достатньо близькі ці числа?»

У серйозних фінансових програмах також використовують модуль decimal, який дозволяє працювати з десятковими числами контрольованим способом.
