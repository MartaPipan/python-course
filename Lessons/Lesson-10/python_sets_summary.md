# Розділ 11. Множини й словники в Python

Множини та словники — це дві потужні вбудовані структури даних у Python, які використовують фігурні дужки `{ }`, але побудовані на абсолютно різних моделях даних.

* **Множина (`set`)** відповідає на запитання: *«Які унікальні значення присутні?»*
* **Словник (`dict`)** відповідає на запитання: *«Яке значення пов’язане з цим ключем?»*

---

## 11.1. Множина усуває дублікати (`set`)
Головна особливість множини — абсолютна унікальність її елементів. Якщо ви спробуєте додати однакові значення, Python автоматично залишить лише один екземпляр.

```python
# Дублікат "КН-11" буде автоматично видалено
groups = {"КН-11", "КН-12", "КН-11"}

print(groups)      # Виведе: {'КН-11', 'КН-12'}
print(len(groups)) # Виведе: 2
```

⚠️ **Важливі правила множин:**
1. **Порядок елементів не гарантується.** Множина — це невпорядкована структура даних. Якщо для вас важлива послідовність або повтори елементів, використовуйте **список (`list`)**.
2. **Множина не має індексів.** Ви не можете звернутися до елемента як `groups[0]`.
3. **Порожня множина** створюється виключно як `set()`. Запис `{}` зарезервований для створення **порожнього словника**.

## 11.2. Додавання, вилучення й перевірка належності

```python
registered = {"Олена", "Марко"}

# 1. Додавання елемента
registered.add("Ірина")     # Тепер: {"Олена", "Марко", "Ірина"}

# 2. Перевірка належності за допомогою оператора "in"
# Працює майже миттєво (за константний час O(1)) незалежно від розміру множини
print("Марко" in registered) # Виведе: True
```

### Різниця між видаленням через `remove()` та `discard()`
Коли потрібно прибрати елемент із множини, вибір методу залежить від того, чи вважається відсутність цього елемента помилкою:
* `registered.remove("Петро")` — **Спричинить помилку (`KeyError`)**, якщо "Петро" відсутній у множині. Використовуйте, коли програма очікує, що елемент обов'язково має бути там.
* `registered.discard("Петро")` — **Безпечне (тихе) видалення**. Якщо елемента немає, програма просто піде далі без жодних помилок.

## 11.3. Операції над множинами (Математичні оператори)
Множини ідеально підходять для порівняння та аналізу кількох груп даних між собою. Розглянемо два списки студентів:

```python
lecture = {"Олена", "Марко", "Ірина"}
practice = {"Марко", "Ірина", "Тарас"}
```

### Основні операції:
| Операція | Оператор | Приклад у коді | Результат | Що це означає? |
| :--- | :---: | :--- | :--- | :--- |
| **Об'єднання** | `|` | `lecture | practice` | `{'Олена', 'Марко', 'Ірина', 'Тарас'}` | Усі студенти з обох груп (без повторів). |
| **Перетин** | `&` | `lecture & practice` | `{'Марко', 'Ірина'}` | Лише ті студенти, які відвідали і лекцію, і практику. |
| **Різниця** | `-` | `lecture - practice` | `{'Олена'}` | Студенти, які були на лекції, але не прийшли на практику. |
| **Симетрична різниця** | `^` | `lecture ^ practice` | `{'Олена', 'Тарас'}` | Студенти, які відвідали тільки одне з двох занять. |

### Додаткові перевірки:
* **Перевірка на підмножину (`<=`):** Вираз `small <= big` повертає `True`, якщо всі елементи з множини `small` містяться всередині `big`.
* **Відсутність спільних елементів (`isdisjoint()`):** Метод `lecture.isdisjoint(practice)` поверне `True`, якщо множини не мають **жодного** спільного значення. У нашому випадку поверне `False`, оскільки Марко та Ірина є в обох групах.
