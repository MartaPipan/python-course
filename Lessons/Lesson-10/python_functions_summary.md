## 12.1. Від повторення до def

```python
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

room = celsius_to_fahrenheit(20)
outside = celsius_to_fahrenheit(5)
print(room, outside)
```

* **`def`** створює функцію, але її тіло виконується лише під час виклику.
* **Параметр** — це змінна у визначенні функції (`celsius`).
* **Аргумент** — це конкретне значення, яке передається під час виклику (`20`, `5`).
* **`return`** передає значення назад і завершує поточний виклик.
* **`print()` і `return` не взаємозамінні!** `print()` лише показує текст на екрані, а `return` дає результат, який можна зберегти у змінну, порівняти або протестувати.

### Кадр виклику та локальні змінні
```python
def weighted_score(labs, exam):
    labs_part = labs * 0.4
    exam_part = exam * 0.6
    total = labs_part + exam_part
    return total

result = weighted_score(75, 90)
```
Під час виклику `weighted_score(75, 90)` створюється окремий **кадр виклику** (stack frame). У ньому `labs` зв’язується з `75`, `exam` — з `90`, а також створюються локальні змінні `labs_part`, `exam_part` і `total`. Після виконання `return` обчислене значення переходить у `result`, а всі локальні імена цього виклику знищуються.

### Повернення None за замовчуванням
Якщо функція доходить до кінця і не зустрічає `return`, вона автоматично повертає **`None`**. Це часто стає причиною помилок типу: `unsupported operand type(s) for +: 'NoneType' and 'int'`.

```python
def safe_ratio(part, whole):
    if whole == 0:
        return None
    return part / whole
```
Тут `None` є частиною контракту: воно означає, що відношення не визначено. Той, хто викликає функцію, повинен спочатку перевірити результат на `None`.

## 12.2. Позиційні, іменовані й стандартні аргументи

```python
def format_student(name, group, active=True):
    status = "активний" if active else "неактивний"
    return f"{name}, {group}, {status}"

print(format_student("Олена", "КН-11"))  # Позиційні аргументи
print(format_student(group="КН-12", name="Марко", active=False))  # Іменовані аргументи
```
* **Позиційні аргументи** пов’язуються строго за порядком їх передачі.
* **Іменовані аргументи** передаються за назвою параметра, тому їхній порядок можна змінювати.
* **Параметри зі стандартними значеннями** (дефолтні) обов'язково ставляться **після** обов’язкових.

⚠️ **Антипатерн: змінювані об'єкти як дефолтні значення!**
Ніколи не використовуйте порожній список `[]` або словник `{}` як стандартне значення:
```python
# ПРАВИЛЬНО:
def add_task(task, tasks=None):
    if tasks is None:
        tasks = []
    tasks.append(task)
    return tasks
```
Стандартні значення обчислюються **один раз під час створення функції (`def`)**, тому `tasks=[]` накопичував би дані між різними незалежними викликами функції.

## 12.3. *args та **kwargs (Змінна кількість аргументів)

* **`*args`** збирає всі зайві позиційні аргументи в **кортеж** (`tuple`).
* **`**kwargs`** збирає всі іменовані аргументи в **словник** (`dict`).

```python
def average(*scores):
    if not scores:
        return None
    return sum(scores) / len(scores)

def describe(**fields):
    for key, value in fields.items():
        print(key, value)
```

### Розпакування готових структур за допомогою зірочок:
Зірочки також працюють у зворотному напрямку — для розпакування списків чи словників перед передачею у функцію:
```python
scores = [72, 81, 90]
print(average(*scores))  # Еквівалентно: average(72, 81, 90)

student = {"name": "Олена", "group": "КН-11"}
describe(**student)      # Еквівалентно: describe(name="Олена", group="КН-11")
```

## 12.4. Локальна й глобальна область видимості (Правило LEGB)

```python
tax_rate = 0.2  # Глобальна змінна

def price_with_tax(price):
    total = price * (1 + tax_rate)  # price та total - локальні
    return total
```
Пошук імен у Python відбувається за строгим правилом **LEGB**:
1. **L**ocal (Локальна область всередині функції).
2. **E**nclosing (Область функції, що охоплює поточну — для вкладених функцій).
3. **G**lobal (Глобальна область поточного модуля/файлу).
4. **B**uilt-in (Вбудована в Python область: `len`, `sum`, `max`, `int`).

⚠️ **Важливо:** Не називайте свої змінні іменами `list`, `sum`, `str`, `max`, оскільки цим ви затіните (перекриєте) вбудовані функції Python.

## 12.5. Ключові слова global та nonlocal

### `global` — рідкісний виняток
Дозволяє всередині функції змінити значення змінної, яка створена на рівні всього модуля (глобально).
```python
visits = 0

def register_visit():
    global visits
    visits += 1
```
*Використання глобальних змінних ускладнює тестування та читання коду.* Краще передавати значення явно:
```python
# ПРАВИЛЬНІШИЙ І ПРОЗОРІШИЙ ПІДХІД:
def register_visit(current_visits):
    return current_visits + 1
```

### `nonlocal`
Використовується у вкладених функціях для повторного зв’язування змінної з найближчої зовнішньої області видимості (але не глобальної). Це є фундаментальною основою для створення **замикань (closures)**.
